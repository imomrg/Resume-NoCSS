# RESUME-NOCSS

## Description
 This project is a simple resume webpage created using HTML only without CSS.
 It presents personal information, education details, skills, and projects in a structured format.

 ## Features
 - Personal information section
 - Education Details
 - Skills section
 - Project section
 - Contact information

 ## Technologies Used
 - HTML5

 ## Project Objective
 To create a structured resume webpage using basic HTML tags without using CSS.

 ## Learning Outcomes
 - Understanding HTML Structure
 - Using Heading, Paragraphs, and Lists
 - Creating tables
 - Organizing webpage content
